## Question

How do two players create and join a room using a shareable four-digit code, become ready, start a round, select a mode, see results, and restart/rematch? Decide leading-zero handling, code uniqueness/reuse/expiry and capacity, full/unknown-room behavior, host departure, disconnect/reconnect, background tabs, multiplayer pause, abandoned rounds, and the lifetime of a player's immutable local name. No accounts or public matchmaking.
