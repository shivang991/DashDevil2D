## Question

Which gameplay values and limits belong in centralized configuration, with which defaults, units, validation, and per-mode overrides? Define which values may vary for tests/playtesting, which must be identical across a multiplayer round, and when configuration is captured or changed. Include HP, hearts, duration, track length, damage, speed, lane transitions and difficulty. Do not invent defaults without preserving or explicitly replacing current behavior.
