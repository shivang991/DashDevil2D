The focus command keeps its `mode` byte for visibility and `ready` byte for focus. `PairedConnection.sendFocus({ visible, focused })` names the two meanings at the caller; the server reads the same bytes. Room phase and movement phase, and seat index and seat-or-none, use different generated types. `Contact.latestSeat` already carries a zero-based seat; its separate domain preserves that behavior and reserves the schema-permitted value 2.

## Structural ownership and intentional literals

Generated shared constants: verification datagram 10 bytes, credential 32 bytes, room code 4 digits, default frame 65,536 bytes, record limit 1,048,576 bytes, uint32 counter ceiling, projection scale 1,024. The 65,536 byte QUIC stream windows are transport tuning, distinct from the frame default. Local 1,024 segment/event history bounds, 120 input backlog, retry and buffer capacities remain implementation limits; they do not share protocol meaning with the projection scale. Gameplay values such as score per coin and durations remain in their current configuration or mechanics. Numeric array indices, seat-count arithmetic, ordinary counters and CSS sizes remain literal where a protocol name would obscure their role. Long Drive's control 3 means acceleration; it is not renamed as multiplayer NOS. Independently authored JSON wire fixtures, malformed-input vectors and expected numeric test data remain literal.

Validation compares the generated layouts against the previous schema for every field order, scalar width, max/mask, bit packing and message ID. Existing codec fixtures and malformed-input tests retain compatibility coverage.

## Production JavaScript

Vite production build, compared with the unchanged `refactor/ui-updates` pilot at `e376dfc`: the three JavaScript assets total 424,045 bytes raw / 130,563 bytes gzip on the pilot and 424,970 bytes raw / 131,184 bytes gzip here (gzip level 9, deterministic timestamp). Delta: +925 raw / +621 gzip. Generated codes emit as scalar bindings and are inlined/minified in the output; there is no runtime enum object or lookup table. The small bundle increase is the disclosed deviation from size neutrality.

The existing browser lifecycle suite currently fails both tests on `refactor/ui-updates` and on this branch at the same assertions: one reads pair generation before recovery finishes; the other waits for a Leave button after random obstacle damage has already ended the round. This branch leaves that unrelated suite unchanged. Room and transport browser suites pass.
