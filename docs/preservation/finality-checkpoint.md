## Approved continuation implementation

The owner approved the canonical-group amendment and continuing work. [#11 amendment](https://github.com/shivang991/DashDevil2D/issues/11#issuecomment-6239984034) and [#14 amendment](https://github.com/shivang991/DashDevil2D/issues/14#issuecomment-6239984266) govern the new implementation. The earlier blocked report above is historical.

Go and TypeScript now retain open event groups across raw tick boundaries and publish the preceding committed checkpoint until the group closes. Boundary inputs precede grouped pickups/healing, damage and finality. Groups are bounded by the existing1024-record authority-history limit; exceeding it fails explicitly. Raw movement still uses n/tickRate intervals. `processedTick` and an explicitly provisional preview let client replay/prediction progress without publishing partial authority. Baseline capture waits for coherent state; queued seat-generation resets follow a nonterminal group commit. Lag abandonment freezes the preceding committed state rather than leaking partial effects.

Shared fixture version3 adds raw-tick-split finishes, next-group finishes, shift/return completion, healing before a fatal obstacle across the split, contested hearts and distinct summed obstacle damage across the split. Literal half-microsecond conversion vectors independently test the exact exclusive boundary; crossing examples avoid pretending that decimal subtraction/bisection produces exact mathematical halfways. Public tests additionally cover withheld checkpoints, same-time input admission, client reconstruction of both cars and a fresh recovery input generation. The original64Hz endpoint fixture now advances through group closure while retaining its exact15625us event time, as explicitly authorized by the amendment.

`pnpm test:groups` adds actual-Chrome recovery and Leave cases in both seats. A declared1Hz test course with a2s lag threshold widens the pending interval for deterministic observation; it does not establish default latency/performance acceptance. Actual server logs prove baseline capture waits for a pending group, and a later Leave cannot overtake the earlier1000000us tie. Grace-expiry cutoff and existing maintenance cutoff have focused Go regressions. This test course changes no shipped defaults or Long Drive behavior.
