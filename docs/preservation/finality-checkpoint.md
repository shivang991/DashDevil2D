## Failure retention and limits

Raw attempts are retained under `apps/client/test-results/finality-implementation/`; each browser invocation also retains its unique `transport-*` directory with server logs, JSON, PNGs and videos. The first typecheck hit the sandboxed default Go cache; direct Go checks use a temporary cache, and full validation requires listener/cache access. The first browser attempt overlapped a source edit and Vite reloaded the page; it is an interrupted/harness failure, not evidence of a game defect. The second browser attempt reproduced the countdown/result defect in both seats. A subsequent reload fixture used a 1500ms delay and exceeded the existing one-second baseline-application deadline; it was corrected to 700ms without changing that deadline. The original failed run remains retained. Initial added fixture attempts also exposed an assertion that assumed seat zero always finishes and invalid placements at/beyond the finite track's finish; their expectations were corrected before counting them as evidence. The corrected endpoint case retains its actual red/green regression.

This closes remaining Drag Race boundary work within Stage 6, not the full Stage 6 gate: Road Rage and the other Stage 6 tickets remain separate. Stage 5 exit is recorded in the lifecycle checkpoint. This work does not claim Stage 7 acceptance, a complete supported OS/browser release matrix, network performance targets, reference-hardware measurements, capacity or recorded two-person/manual audiovisual acceptance. Actual local Chrome and agent screenshot inspection supplement unit tests; they cannot replace those later requirements. A failed applicable gate still blocks progression.
