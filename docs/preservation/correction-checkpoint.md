## Failure retention and measurement limits

All red tests, command logs and browser attempts remain in ignored `apps/client/test-results/correction-implementation/` and unique `apps/client/test-results/transport-*` run directories. No original failure is erased or counted as passing. The first Go check could not access the default cache; setting GOCACHE alone was filtered by Turbo's strict environment, so final checks explicitly use `--env-mode=loose` with the temporary cache. The first browser attempt ran during source edits and Vite reloads disrupted pages. The second attempt passed delayed/recovering/unordered scenarios but clean delivery exposed a settling-window accounting defect. Subsequent tests and independent review fixed that defect and replaced scheduled-duration measurement with a monotonic receipt-to-cleared-frame observation. The final swept-path regression exposed a visual crossing below the ordinary snap thresholds; it now snaps immediately.

macOS denies `/dev/bpf0` access for the attempted loopback UDP capture, even outside the execution sandbox. Chrome NetLog was also tried and did not expose the WebTransport traffic needed for this measurement; that capture option was removed. QUIC/UDP/IP overhead, a 60-second ordinary budget window and statistically sufficient normal/degraded network performance remain **unavailable/unestablished**, not passed. Application-byte observations do not substitute for that requirement. No configured network profile is represented as a measured network impairment. Draw-based settling measurements retain display-scanout/compositor uncertainty.

The remaining measured network/performance acceptance is tracked by [#43](https://github.com/shivang991/DashDevil2D/issues/43), supported releases by [#42](https://github.com/shivang991/DashDevil2D/issues/42), capacity by [#44](https://github.com/shivang991/DashDevil2D/issues/44) and human/full acceptance by [#45](https://github.com/shivang991/DashDevil2D/issues/45).

This checkpoint records the Stage 5 correction implementation slice. It does not establish full Stage 5 exit, Stage 6/7 acceptance, the supported browser/OS matrix, reference-hardware performance, three seeded ten-minute performance runs with the required sample counts, capacity or two-person manual playtests. No failed gate authorizes progression or relaxed requirements.
