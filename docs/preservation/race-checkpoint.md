## Scope and governing decisions

This is the clear-track countdown → drive → confirmed finish slice. Shipped configuration defaults are unchanged. `infra/clear-track.json` is an explicit, validated configuration: 2400-unit finish, 400-unit/s normal speed, 2× NOS, no random or reserved road objects.
