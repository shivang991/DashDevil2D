## Fixture and evidence discipline

The public server tests replace only the clock and random code starting point through constructor boundaries; the product admission, WebSocket and QUIC/WebTransport stack remain real. I/O deadlines and application-progress timers retain real time. Integer microseconds, decisions, result reasons, identities and bytes compare exactly. Existing Go/TypeScript position tolerance remains `1e-6 + 1e-12 * abs(expected)`; no simulation fixture tolerance or expected wire bytes changed.

`infra/lifecycle-boundaries.json` is an explicit test override of the shipped default Drag Race configuration. It changes room timing only, not default-course mechanics. Browser seeds/configurations and host environments are captured by each unique transport manifest; tests attach JSON and full-page screenshots. Video remains retained where a harness records it; the new manually created browser contexts do not enable video capture. Exact microsecond cutoff evidence comes from the public server clock fixtures; real-browser observations establish visible flows, not sub-microsecond browser timing measurements.

Raw command attempts remain in `apps/client/test-results/issue37/`; every transport invocation retains a unique directory under `apps/client/test-results/transport-*`. Original failures are retained, including sandbox cache denial, consumed-broadcast fixture setup, a mistaken relative edit path, the initial expiry UI regression, and browser reload returning to the main menu before mode selection. The abandonment server fixture originally advanced its clock before the network leave was applied; it now waits for observed channel closure. Independent review reproduced expiry-first versus disconnect-first divergence; the fixed regression now passes both orders. The race detector identified an existing internal fixture calling a Locked method without its mutex; the fixture now acquires that lock. Those setup failures are not claimed as product red tests. Timer/no-op/client-expiry regressions were observed failing before their fixes; other boundary cases extend coverage and are not mislabelled red-first.
